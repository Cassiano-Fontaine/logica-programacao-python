# Lógica de Programação com Python

Repositório criado para reunir exercícios de lógica de programação desenvolvidos durante meus estudos na DIO.

## Sobre o projeto

O objetivo é praticar os fundamentos da programação utilizando Python, trabalhando com variáveis, operadores, condições, estruturas de repetição, listas e funções.

## Exercícios

- Operações matemáticas
- Verificação de números pares e ímpares
- Cálculo de média de notas
- Tabuada
- Comparação de números
- Manipulação de listas

## Tecnologias utilizadas

- Python
- Git
- GitHub

## Como executar

Clone o repositório, acesse a pasta dos exercícios e execute o arquivo desejado com Python.

```bash
python exercicios/01_operacoes.py
```
